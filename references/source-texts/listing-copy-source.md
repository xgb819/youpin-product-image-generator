# 上架名称与卖点：用户提供文本摘录

来源为用户提供的《产品站规范2.0——阶段一商品名称和卖点使用规范》粘贴文本；原件自述2022年8月26日起生效。本文件只摘录本次7字段相关文字，省略示例图片、外部协作表、联系方式与无关工作流程。不是对当前在线规范的独立认证；未打开原件内其他链接获取未提供条文。

## L01 字段与前台位置（原文）

- 商品名称：30字，出现在搜索列表
- 商品简称：8字，出现在信息流产品名称下、众筹生活优选频道页和秒杀页面
- 商品描述：30字，搜索产品标题下
- 商品简述：13字，信息流产品标题下
- 核心卖点1-3：24字，产品站标题下

## L02 长标题、短标题（原文摘录）

- 长标题多PID或者单PID建议都不加规格描述，确保用户感受统一直观
- 单一PID商品名称（控制在20字之内）：【xx明星推荐】（选填）+品牌+产品系列名称（选填）+核心卖点（建议1-3点）+产品名
- 多PID商品名称（控制在20字之内）：【xx明星推荐】（选填）+品牌+产品系列名称（选填）+核心卖点（建议1-3点）+产品名
- 商品简称（8字）：核心卖点（建议1-2点）+产品名
- 如需出现品牌，且品牌中英文都有，出现中文品牌名即可（除品牌另有规定）
- 商品名称不可出现“有品”、“小米有品”

原文另规定明星推荐需在授权期内、提供授权书并通过审核，不能出现“牙医推荐”“爆品推荐”等模糊推荐。本项目普通文案模式不自动放行明星背书；有授权的特殊情形需专项核对，不把此实现边界说成官方禁止所有明星推荐。

## L03 名称格式（原文摘录）

- 产品名称在品牌后加英文空格，其他位置不出现任何符号和标点断句
- 不用竖线、斜线、「」、・、【 】、+等符号断句
- 如需要引号，用英文的双引号" "
- 特殊情况：商品名称中如出现平行类目产品，类别可用斜杠，如：认养一头牛 牛奶/酸奶，如出现两个以上类目，名称用：组合
- 标题中出现英文单词，英文单词首字母大写其他字母小写（特殊名词例外），英文应为用户普遍熟知的词，不用生僻词
- 规格单位需按照规范用英文标注：毫升（mL）、米（m）、千米（km）、厘米（cm）、克（g）、千克（kg）
- 不可以出现“雷总同款”、“雷总直播间”和“雷总推荐”，接入米家的产品可以用“接入米家”
- 三方产品不能跟雷总、小米、小米有品等重要品牌资产内容同时使用，不能让用户认为这是小米的产品
- 不要带运营信息：如“新品”、“有品定制”、“内购”、“新人专享”、“包邮”

## L04 卖点（原文摘录）

- 卖点直接从产品站头图和前几页中选择展示核心功能或吸引人的卖点
- 只能出现产品本身功能类突出卖点，不可出现促销类卖点
- 断句：用英文逗号
- 应用软件统一用：App
- 不用竖线、「」、・、【 】、+
- 如需要引号，用英文的双引号" "
- 核心卖点每一点结尾不加标点
- 3个核心卖点不能为重复内容；卖点不能直接复制产品名称
- 多PID产品，例如存在高低配置版本，卖点需展示共性信息，或标明高低配置版本不同卖点等信息
- 卖点不出现促销或折扣类信息
